# Simple Calculator

A beginner-friendly command-line calculator in Python.

A beginner Python project by Shadan, a Class 11 PCM student learning Python.

## Features

- Add, subtract, multiply, and divide
- Input validation for numbers and menu choices
- Handles division by zero with a clear error message
- Simple menu that runs until you choose to exit

## How to run

```bash
python3 simple-calculator.py
```

Then choose an operation from the menu, enter two numbers, and see the result.
